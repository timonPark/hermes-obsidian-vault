### v4 수정 방향 (보류 — 학습자 요청으로 v3 유지)
1. **옵시디언 기초(1~5회차)는 압축**하되 빼지 않는다. 속성(frontmatter)은 더 깊게 다룬다
   - 이유: 서비스 입장에서 옵시디언 노트는 "사람도 읽을 수 있는 데이터베이스"이고, 속성이 데이터 구조가 됨
2. **"만드는 사람" 회차를 추가**한다
   - 헤르메스를 다른 프로그램에서 호출하는 방법 (API Server, MCP, 플러그인)
   - 스킬로 기능 만들기, 여러 사용자가 쓸 때의 권한·보안·비용
3. **졸업 과제를 "팀에 시연할 프로토타입"으로 변경**한다
   - 0회차 과제도 "반복 업무 3가지" → "프로토타입으로 보여주고 싶은 장면 3가지"로 변경
