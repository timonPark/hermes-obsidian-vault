## 2. 배운 것
- **볼트 = 폴더.** 새로 만드는 게 아니라 기존 폴더를 "볼트로 열기"
- 용어 구분: **볼트 열기** ≠ **연동**(헤르메스와 옵시디언 연결, 11회차)
- **노트는 내 것, `.obsidian`은 옵시디언 것**
  - `app.json`(기본 설정), `appearance.json`(화면), `core-plugins.json`(기본 기능), `workspace.json`(열린 탭·배치)
  - 헤르메스가 건드리지 못하게 막을 폴더 (11회차)
  - `workspace.json`은 Git 백업에서 제외 (5회차 `.gitignore`)
  - Finder에서 숨김 폴더 보기: `Cmd + Shift + .`
- 단축키

  | 단축키 | 기능 |
  |---|---|
  | `Cmd + O` | 빠른 전환 (노트 이름으로 열기) |
  | `Cmd + P` | 명령 팔레트 (모든 기능 검색) — 이것 하나만 기억해도 됨 |
  | `Cmd + N` | 새 노트 |
  | `Cmd + E` | 편집 ↔ 읽기 모드 |

- 검색 문법 (검색창: `Cmd + Shift + F`)

  | 문법 | 의미 | 볼트에서 해본 예 |
  |---|---|---|
  | `단어` | 본문·파일명에서 찾기 | `슬랙` |
  | `"문구"` | 띄어쓰기 포함 정확히 일치 | `"업무 기록"` |
  | `path:폴더` | 특정 폴더 안에서만 | `path:progress 슬랙` |
  | `file:이름` | 파일 이름으로 찾기 | `file:review` |
  | `-조건` | 제외하기 | `헤르메스 -path:curriculum` |
  | `[속성:값]` | 노트 맨 위 속성으로 찾기 | `[status:완료]` |

  - 12회차 이후 업무 기록이 쌓이면 `path:wiki [type:지시] 보고서` 같은 조합으로 씀
  - `[속성:값]` 검색이 되려면 노트에 속성이 있어야 함 → 4회차와 연결

## 7. 팀장 코멘트
- 속성 검색을 고른 건 프로젝트의 핵심을 짚은 것. 헤르메스가 업무 기록에 `type`, `project`, `due` 같은 속성을 붙이면 옵시디언만으로도 `[type:지시] [project:A]` 검색이 가능해짐
- 속성은 4회차에서 설계. 어떤 속성을 둘지가 곧 업무 기록 시스템의 데이터 구조
