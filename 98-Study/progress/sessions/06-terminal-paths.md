# 06 — 터미널과 파일 경로

> 커리큘럼: [[curriculum]] · 현황판: [[progress]] · 이전 회차: [[05-vault-design-git-backup]]

## 1. 오늘 한 것
- 학습자가 5회차에서 `cd`, `git` 등 터미널을 이미 자연스럽게 사용 → 기본 명령 설명 생략
- 주제 1: 헤르메스 설치 전에 알아둘 터미널 개념 (홈 폴더, 숨김 폴더, 환경 변수, PATH)

## 2. 배운 것
| 개념 | 의미 | 헤르메스에서 |
|---|---|---|
| `~` | 홈 폴더 (`/Users/2309-n0018`) | 설정이 `~/.hermes`에 생김 |
| 숨김 폴더 | `.`으로 시작, `ls -a`로 보임 | `~/.hermes` |
| 환경 변수 | 프로그램이 읽는 "이름=값" | API 키는 `~/.hermes/.env`에만 |
| `PATH` | 명령어를 찾는 폴더 목록 | 설치 후 `hermes`가 안 먹으면 대부분 이 문제 |

- `~/.hermes`는 **볼트 밖**. 볼트는 GitHub에 올라가지만 헤르메스 설정은 올라가지 않음 → 둘을 섞지 않는다

## 4. 막힌 점과 질문
- Q. GitHub 이슈 등록 → 브랜치 → PR로 진행하면 안 되나?
  - A. 6회차 실습은 읽기 명령뿐이라 필요 없음. 단, 이 방식은 **11회차부터 헤르메스 작업에 적극 권장** (PR 화면 = AI 변경 검토·승인 단계)
  - 학습자 결정: 6회차는 그냥 진행. 이후 적용 여부는 학습자 판단
